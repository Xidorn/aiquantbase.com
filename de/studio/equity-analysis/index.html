Verstehen, was die Reihe zeigen kann

Ein Portfoliowertverlauf aus Beobachtungswerten beschreibt Veränderungen zwischen den gelieferten Beobachtungen. Er kann weder Verluste zwischen Beobachtungen rekonstruieren noch eine Trefferquote auf Trade-Ebene ableiten. Das Tool lädt keine Kurse, führt keine Strategieregeln aus, bereinigt keine Zahlungsströme und schätzt keine Transaktionskosten.
