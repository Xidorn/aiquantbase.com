Eine Strategiebeschreibung erstellen

Präzisieren Sie die Regeln, prüfen Sie Ihre Annahmen und exportieren Sie eine wiederverwendbare Dokumentation. Beginnen Sie mit einer Vorlage oder einer leeren Beschreibung.

LOKALER ARBEITSBEREICHSo funktioniert es ↗
01

Die Regeln definieren

Das Laden einer Vorlage ersetzt die aktuellen Felder. Vorlagenregeln dienen als Beispiele und bleiben bearbeitbar.

02

Prüfen & exportieren

Dies ist ein strukturiertes Regeldokument. Es werden weder Modelle aufgerufen noch Strategien ausgeführt.

Ihre Beschreibung erscheint hier, nachdem Sie die Felder ausgefüllt und „Beschreibung erstellen“ gewählt haben.
JSON kann erneut importiert werden. Beim Neuladen oder Schließen der Seite gehen nicht exportierte Änderungen verloren.

Bereit. Wählen Sie eine Vorlage oder schreiben Sie Ihre eigene Beschreibung.
