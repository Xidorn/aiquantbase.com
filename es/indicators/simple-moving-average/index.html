Media móvil simple: cálculo y tiempos

Una media móvil simple es la media aritmética de un número fijo de observaciones. El campo de entrada y la ventana determinan qué mide.

Equipo editorial de AI Quant BasePublicado 2026-10-26Actualizado el 2026-10-26

Calcula una media móvil

Para n observaciones, SMA = suma de las últimas n entradas dividida entre n. Una secuencia ilustrativa 10, 12, 14 tiene una SMA de tres observaciones igual a 12. Son valores construidos, no datos de mercado.

Define cuándo está listo el cálculo

Un cálculo de ventana completa requiere n observaciones. Especifica cómo se comporta la estrategia durante el periodo inicial y si está completa la información de la barra actual. Una media de precios de cierre no debe considerarse conocida antes de ese cierre.

Separa el indicador de la estrategia

Una SMA resume observaciones pasadas. Una estrategia sigue necesitando reglas de entrada, salida, tamaño y ejecución. El suavizado cambia la respuesta a los nuevos datos de entrada; no demuestra por sí solo valor predictivo.
