Créateur de fiches de stratégie

Documentez les règles nécessaires à un test pertinent : univers, disponibilité des données, entrée, exécution, sortie, taille de position, coûts et validation.

Ouvrir le créateur ↗Explorer les modèles ↗

Partir d’une hypothèse précise

Sélectionnez un modèle de suivi de tendance, de retour à la moyenne ou de rotation d’ETF. Remplacez les hypothèses illustratives par vos propres décisions de recherche. Chaque champ reste modifiable.

Conserver un document transmissible

Exportez en Markdown pour la lecture ou en JSON pour une réimportation ultérieure. Le fichier consigne toutes les règles saisies et la version de l’outil. Il ne contient pas de code de stratégie exécutable.

Garder les décisions de recherche visibles

Le créateur vérifie les champs requis et le format du fichier. Il ne peut déterminer si une hypothèse est économiquement fondée, si les données sont utilisées sous licence ou si les règles sont rentables.

Une prochaine étape claire

Implémentez et testez la spécification dans l’environnement de recherche de votre choix. Consignez les versions des données, les coûts et les changements de paramètres, puis examinez une série de valeur du portefeuille adaptée dans l’outil d’analyse.

Aucun modèle n’est appelé et aucun backtest n’est exécuté. Les paramètres des modèles illustrent la description de règles ; ce ne sont pas des réglages de trading recommandés.
