Equity CSV & research file format

Required columns, date rules, cash-flow assumptions and JSON import behavior for the AI Quant Base research studio.

A compact input format

The first row contains date,equity in that order. Supply 2–5,000 observations using UTF-8 text and comma separators. Dates use YYYY-MM-DD, between years 1900 and 9999, strictly from earliest to latest. Repeated dates and extra columns are rejected.

CSV numbers use a decimal point (1234.56), without thousands separators. Commas separate columns.

date,equity
2024-01-01,100
2024-06-01,120
2024-10-01,90
2025-12-31,121

Constructed teaching data, not a measured strategy return.

Values and file limits

Equity must be numeric and positive, from 0.000000000001 to 1,000,000,000,000 inclusive. Decimal and scientific notation are supported. Do not include currency symbols, thousands separators or spreadsheet formulas. Files are limited to 500,000 bytes; text is also limited to 500,000 characters. Quoted CSV values and a UTF-8 byte-order mark are accepted.

Cash-flow basis comes first

A deposit can raise an account balance without investment gain. Confirm that there are no external deposits or withdrawals, or provide an already adjusted series. This tool does not perform the adjustment or calculate a money-weighted return. If the basis is unknown, calculation is blocked. Cost treatment is declared separately and does not change the input series.

Reopen a research file

The brief builder accepts its own aiquantbase.strategy-brief.v1 JSON format. Equity analysis accepts aiquantbase.equity-report.v1 JSON and recalculates every metric from its observations. Editing stored metric fields does not change the recalculated result. Imported data is treated as user-provided, not independently verified.

Local processing and saving

Input text and selected file contents are processed in the current tab. No upload, model API or automatic cloud saving is implemented. Export JSON to preserve the inputs and reopen them later; closing or refreshing the page clears unexported edits.
