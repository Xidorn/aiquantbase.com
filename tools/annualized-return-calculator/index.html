Calculation method

Years = Holding days / 365
CAGR = (Ending value / Starting value)^(1 / Years) − 1

Assumptions & scope

This endpoint calculation assumes no external deposits or withdrawals. It requires positive starting and ending values. Short periods can produce extreme annualized numbers; CAGR does not describe the intervening path or forecast future returns.

Worked example

Illustrative inputs: starting 100, ending 121 and 730 days produce a 10% CAGR using the fixed 365-day convention.
