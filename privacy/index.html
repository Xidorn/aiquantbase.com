Privacy information

Information about this static website, local calculations and external links.

Website operation

AI Quant Base is operated by Mr Wang. Questions concerning this notice can be sent to info@aiquantbase.com.

Calculator inputs

Strategy text, selected files and calculator inputs are processed in the current browser tab and are not sent to AI Quant Base. No automatic saving is implemented; export files before closing or refreshing the page. It does not include an account system, a submission endpoint, third-party analytics scripts or advertising scripts.

Hosting and contact

Serving web pages necessarily involves requests to the hosting provider. Its network and server logging depend on the deployed hosting configuration. Sending email shares the information you choose to include with the relevant mail services and mailbox recipient. Do not send account passwords or API secrets.

External websites and changes

Reference links lead to independent websites with their own privacy terms. If the website later adds analytics, forms or accounts, this notice should be updated to describe the actual implementation before those changes go live.
