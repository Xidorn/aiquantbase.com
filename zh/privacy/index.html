隱私說明

有關靜態頁面、本地計算和外部鏈接的信息說明。

網站運營

AI Quant Base 由王先生運營。有關本說明的問題可發送至 info@aiquantbase.com。

計算器輸入

策略文本、所選文件與計算器輸入均在當前瀏覽器頁面內處理，不向 AI Quant Base 發送。當前未實現自動保存，請在關閉或刷新前導出文件。當前代碼不包含賬戶系統、信息提交接口、第三方統計腳本或廣告腳本。

訪問與聯繫

訪問網頁需要向託管服務發送請求，網絡和服務器日誌取決於實際部署配置。發送郵件會將自行提供的信息交給相關郵件服務與郵箱接收方。請勿發送賬戶密碼或 API 密鑰。

外部網站與變更

參考鏈接指向獨立網站，適用各自的隱私條款。未來若增加統計、表單或賬戶，應在上線前根據實際實現更新本說明。
