淨值分析與回撤報告

用明確的計算口徑分析帶日期的淨值序列，同時保留可導出的輸入記錄。

分析我的數據 ↗查看數據格式 ↗

導入自己的觀察值

使用 date,equity 兩列 CSV，包含按時間排列的 2—5,000 個正淨值。計算前檢查有效日期、重複日期和數值。

查看四項基礎結果

根據輸入序列計算期間總變化、365 天口徑 CAGR、採樣最大回撤和觀察值數量。圖表使用實際觀察日期。

明確現金流與成本口徑

確認期間無外部入金或出金，或使用已調整外部現金流的序列。成本按用戶聲明標註，工具不會估算或額外扣除費用。

可重新導入的報告

導出 Markdown 摘要，或包含原始觀察值與計算版本的 JSON。重新導入 JSON 時會重新計算指標，不直接採信文件內存儲的結果。

淨值路徑不能確定逐筆勝率、解釋所有敞口或還原未觀察損失。本版不計算夏普比率，也不反推逐筆交易。
