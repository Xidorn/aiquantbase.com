淨值 CSV 與研究文件格式

AI Quant Base 工作臺所需列名、日期規則、現金流假設與 JSON 導入行爲。

簡潔的輸入格式

首行按順序使用 date,equity。UTF-8 文本、逗號分隔，包含 2—5,000 個觀察值。日期採用 YYYY-MM-DD，年份爲 1900—9999，嚴格從早到晚排列。重複日期和多餘列會被拒絕。

CSV 數值使用小數點（1234.56），不加千位分隔符；逗號用於分隔欄位。

date,equity
2024-01-01,100
2024-06-01,120
2024-10-01,90
2025-12-31,121

人工構造的教學數據，不是實測策略收益。

數值與文件限制

淨值必須爲正數，範圍包含 0.000000000001 至 1,000,000,000,000。支持小數和科學計數法，不使用貨幣符號、千位分隔符或電子表格公式。文件限制爲 500,000 字節，文本同時限制爲 500,000 個字符。接受帶引號的 CSV 單元格和 UTF-8 字節順序標記。

先確認現金流口徑

入金可以抬高賬戶餘額，但不代表投資收益。請確認期間無外部入金或出金，或提供已調整的序列。工具不執行現金流調整，也不計算資金加權收益；口徑未知時不會計算。成本口徑單獨聲明，不會改變輸入序列。

重新打開研究文件

策略編輯器接受自身導出的 aiquantbase.strategy-brief.v1 JSON。淨值分析接受 aiquantbase.equity-report.v1 JSON，並根據觀察值重算全部指標。修改文件中的指標字段不會改變重算結果。導入數據均視爲用戶提供，未經獨立覈實。

本地處理與保存

輸入文本與所選文件在當前頁面內處理，未實現上傳、模型 API 或自動雲端保存。請導出 JSON 保存輸入，以便稍後再次打開；關閉或刷新會清除未導出的編輯內容。
