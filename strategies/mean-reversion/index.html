Mean reversion: defining the reference

A mean-reversion hypothesis expects a deviation from a defined reference to narrow. The reference, horizon and exit rule determine what is actually being tested.

AI Quant Base editorialPublished 2026-10-26Updated 2026-10-26

Choose a measurable deviation

A research rule might measure the distance between price and a rolling average, or a standardized residual. Specify whether the reference uses only observations available at the decision time. Price, spread and return deviations are different hypotheses.

Make the exit explicit

Define what counts as convergence, how long a position can remain open and what invalidates the idea. A growing deviation can reflect a changed market condition rather than a temporary error. Position limits need to be specified independently.

Use a controlled experiment

As an original research exercise, write two versions that differ only in the exit rule and keep the same data and cost assumptions. Compare their trade records, not just headline returns. No empirical outcome is implied by this exercise.
